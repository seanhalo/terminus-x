Version 1.9 · 轻简与新页｜2026.11.9
  • 新页面结构
    改为四页 App 式布局：首页 / 地图 / 通勤 / 设置，底部常驻悬浮岛切换，二级内容保留原页面。
  • 悬浮岛
    底部改为液态玻璃悬浮岛，选中项为雾面胶囊，切换时胶囊滑动过渡，不再硬切。
  • 轻简主题
    新增第四套主题「轻简」：纯白纯色，无玻璃、无渐变、无阴影，用 1px 细线分层，渲染压力最低。
  • 多个新彩蛋
    任意主题下双击 Hero，进入多款自制离线小游戏。
  • 预约车队的士
    通勤工具新增「预约车队的士」入口。
  • 统一圆角
    卡片 24px，悬浮岛与选中胶囊为胶囊形，标签胶囊化，圆角层级统一。
  • 英文版
    新增英文版：设置页「语言」可在简体中文 / English 之间切换，全站文案、数据映射与更新日志均支持英文。
Version 1.8 · 端侧自学习｜2026.11.6
  • 自学习端侧推理引擎（Pro）
    37 参数微型多层感知机，原生 JS 与 Float32Array 实现，训练与推理均在本地完成，无云端依赖。
  • 历史回放预热
    首次启动以历史行程批量校准，缩短冷启动周期。
  • 渐进接管
    按样本数线性混合静态推算与模型输出，样本达 5 次后完全接管。
  • 赛博足迹
    地图轨迹改为连续红色折线，支持本地持久化与跨日重置。
  • 启程检查单
    出门打卡前核对随身物品，全部确认后自动开始计时。
  • 优雅降级
    数据缺失或异常时跳过学习，不影响打卡主流程。
  • 界面与数据
    浅色/深色背景改为固定双色渐变，深色模式降低蓝色饱和度；天气仅用于训练，口岸取出门时刻快照。
  • 逐光主题
    新增第三套主题「逐光」，暮光暖深配色，背景随时间插值变化；复用深色结构，地图沿用深色。
Version 1.7 · 手感与兜底｜2026.11.3
  • 启程检查单
    出门前逐项确认随身物品，全部确认后自动开始计时；支持最多 6 项自定义物品。

  • 分段控件
    今日 / 明日高亮与自动切换保持同步。
  • 口岸卡片

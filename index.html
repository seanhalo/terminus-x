Version 1.5 · 秩序与呼吸｜2026.10.29
  • 全新视觉材质：液态玻璃
    全局引入极致通透的液态玻璃（Glassmorphism）。主卡片、二级页、设置弹窗与输入框全部告别死板色块，升级液态玻璃质感
  • 彻底扑杀“系统蓝”
    移除返回箭头、ETA 数字、底部图标、选中胶囊与主按钮上的所有系统默认蓝，部分回归黑白灰单色体系。
  • 红绿灯语义回归
    恢复状态圆点的红、黄、绿语义：畅通绿、一般黄、拥堵红；深色模式统一降为半透明。
  • 打卡状态机终极重构
    P1 保留 72px 巨无霸时间招牌，P2、P3 自动缩放并全卡片化；所有操作按钮统一为四个汉字（我已出门 / 我已到校 / 撤销出门 / 撤销记录），节奏一致。
  • 信息降噪
    删除无数据的“深圳端出境”模块，净化天气卡片多余横线，切除“已迟到，快去学校”这类提示。
  • 底层接口与逻辑重构
    重写屿巴 NLB 接口、修复班次拉取错误；全面移除 ETA 缩写；修复“今日/明日”切换与休息日判断缺陷，并根除时间刷新残影闪烁。
Version 1.4 · 进化与呼吸｜2026.10.25
  • 全新深色模式视觉，引入深空靛蓝、玻璃拟态与极光数字特效
  • 新增“通勤状态机”打卡功能，精准记录出门与到校时间
  • 新增全局手动刷新按钮，支持一键拉取最新天气、口岸及交通状态
Version 1.3 · 纯粹与呼吸｜2026.10.23
  • 全新外观系统
    支持手动切换深色模式。暗夜下采用极深黑灰底色，顶部伴随微弱的深蓝紫渐变光晕，模拟晨昏交替的呼吸感；卡片采用发光玻璃边框，倒计时数字带有专属荧光效果，暗光护眼。
  • 离家进度可视化
    倒计时下方新增极细进度条，直观呈现剩余时间占比。时间充裕为绿色，临近出门15分钟内变黄，超时变红。

    全局加入平滑主题过渡动画，无感切换明暗交替。
  • 设置体验优化
    修复 iOS 端时间输入框原生样式导致的横向溢出问题。

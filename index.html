Version 1.4 · 进化与呼吸｜2026.10.25
  • 全新深色模式视觉，引入深空靛蓝、玻璃拟态与极光数字特效
  • 新增“通勤状态机”打卡功能，精准记录出门与到校时间
  • 新增全局手动刷新按钮，支持一键拉取最新天气、口岸及交通状态
Version 1.3 · 纯粹与呼吸｜2026.10.23
  • 全新外观系统
    支持手动切换深色模式。暗夜下采用极深黑灰底色，顶部伴随微弱的深蓝紫渐变光晕，模拟晨昏交替的呼吸感；卡片采用发光玻璃边框，倒计时数字带有专属荧光效果，暗光护眼。
  • 离家进度可视化
    在巨大的倒计时下方新增极细进度条，直观呈现剩余时间占比。时间充裕为绿色，临近出门15分钟内变黄，超时变红。
  • 性能与质感打磨
    全局加入平滑主题过渡动画，无感切换明暗交替。
  • 设置体验优化
    修复 iOS 端时间输入框原生样式导致的横向溢出问题，强制文字左对齐，页面更规整。
Version 1.2 Stable｜2026.10.23
  • 修复屿巴数据源请求错误，深圳湾B2、B2P、B2X可正常拉取预计到站时间
  • 界面文案优化，移除全部ETA缩写，统一使用易懂中文表述
  • 通勤规划逻辑重构，按时段自动切换今日/次日通勤，支持手动切换，修复休息日判断逻辑缺陷
Version 1.2 · 真实，才有意义｜2026.10.22
  • 新增更新日志：可在信息面板查看版本变更记录
  • 实时公共交通时刻：东铁线、九巴、城巴、屿巴接入官方实时到站数据
  • 口岸判断优化：切换居民通道等候分级，拥堵惩罚规则更贴合通勤节奏
  • 双源气象：香港天文台、Open-Meteo直连，两地天气更稳定可靠
  • 东铁延误提示：终点站显示中文，列车延误附带暖色标记
  • 休息日智能识别：自动识别周末与香港公众假期；明日休息时，自动停用通勤推算
  • 稳健降级机制：单一数据源获取失败，不会阻塞页面核心通勤计算
Version 1.1 · 晨昏线｜2026.10.21
  • 品牌与底层架构重构：项目更名晨昏线 Terminus X，重构为SPA多视图架构，搭建首页、港铁视图、巴士视图整套页面框架
  • 通勤协议系统上线：全新设置面板，支持自定义住址、学校、上课时间、保底通勤时长；支持自选主次出行口岸，配置本地持久保存
  • 公共交通视图就位：独立港铁、巴士页面搭建完成，UI与交互全部落地，为实时数据源预留完整接入接口
  • 口岸渲染逻辑升级：口岸不再硬编码，跟随用户配置动态渲染，配套导航链接动态生成
  • UI体系统一：全套iOS极简视觉规范、状态圆点、动画过渡效果落地
Version 1.0 · Original 双城穿梭｜2026.10.20

  • 双城数据看板基础：深圳、香港两地天气面板、口岸等候状态面板

Version 1.14｜2026.11.29
  • 行程记录合并
    打卡、历史、学习记录和口岸样本现在归到同一段行程里；旧数据会自动迁移，备注、返程和口岸信息也不再分散。
  • 出门时间更稳
    预测会参考平时同一时段的实际耗时，只在样本足够时做小幅修正；样本不够就继续按路线计划，不硬给一个看似精确的时间。
  • 口岸预测修正
    口岸等待改用出发时的排队情况判断，不再用到达时的拥堵倒推；返程按出境方向计算。
  • 编辑行程快捷入口
    编辑已保存的地铁段时，预计用时下方可以直接查看时刻表或车费；深圳地铁只提供车费，香港港铁两项都有，并自动带入线路、站点和方向。添加行程时不显示。
  • 香港假期
    内置 2026–2027 假期，接口改走代理更新；超出已覆盖年份时显示“假期数据待更新”，避免把未知日期当成正常上课。
  • 界面
    弹窗统一为居中卡片和轻液态玻璃；逐光主题删去固定高度光层和底部光晕，修复清晨背景横线。
Version 1.13 稳定版｜2026.11.26
  • 中英文补全
    车费计算器、港铁站点与全局语言切换补齐英文；港铁站名英文优先、中文副标题，深圳站名保留中文。
  • 车费稳定性
    票价数据增加解包校验与 4bit 上限元信息；异常时显示明确提示；清理重复英文键与 i18n 静态缓存。
  • 键盘与弹层
    站点 / 线路选择弹层在键盘打开时保持原位，不再整体上移；搜索框、行高与间距统一放大。
  • 口岸 ETA
    到口岸后立即隐藏，不再持续后移；返程不显示口岸 ETA，进入深圳后切换为到家距离。
  • 定位状态
    地图按钮与实际定位状态同步；关闭定位可一次关闭全部；权限拒绝不再自动重试，临时失败改为指数退避；地图与通勤不再双开。
  • 动效
    时间变化、页面切换方向、打卡状态、按钮按压与地图足迹绘制加入轻动效，支持“减少动态效果”。
Version 1.13 · 归并与呼吸｜2026.11.24
  • 车费计算器
    新增车费计算器，覆盖深圳地铁与港铁；选择起终点并切换成人 / 学生后，按官方票价表计算，并拆分普通票价、学生优惠、东铁线头等车厢附加费与机场快线票价。
  • 票价口径
    深圳地铁使用官方票价表，港铁使用官方票价与机场快线数据；按最短路径 / 官方站对价计算，暂不含商务车厢；机场快线不设学生优惠。
  • 双主题下线
    为了方便后续改进调整，减少重复适配与工作量；同时统一设计风格，去掉过于花哨的视觉分支。基于以上考虑，正式下线深色与轻简主题。
  • 口岸预测简化
    MLP-B 只在真实去程状态下触发；GPS 精度 <300m 且距最近口岸 <300m 时，首帧即记录；一次去程只记一条（以 morningOut 作为 tripId），撤销出门不删除已记录样本；取消 8 秒停留、3 帧定位与 05:00–11:30 时间窗。
  • 通勤定位省电
    GPS 只在上学 / 放学路上开启，到校 / 到家打卡后自动暂停，撤销到校 / 到家后恢复。
Version 1.12 · 通勤路径与多线时刻表｜2026.11.21
  • 通勤路径
    设置页新增「通勤路径」，按段记录去程路线并累加总时长；仅作个人记录，不参与首页建议出门时间的计算。
  • 六类行程段
    步行、地铁、公交 / 巴士、转乘、到达口岸、过关；每段填线路与起讫点、预计用时，转乘默认同站，另支持香港 ↔ 中环、尖沙咀 ↔ 尖东出站换乘。
  • 线路与站点
    深圳地铁 17 条线与港铁 10 条线可直接选站；深圳 867 条、香港 1055 条巴士线路可搜索；香港巴士选线后自动带出站点，断网回退手填。
  • 实测回写
    开始行程后逐段「到达」或「跳过」；实测分钟直接写回该段预计用时，跳过的段保留原值，累积时间同步更新。
  • 港铁多线时刻表
    由东铁线扩展为十条线，可选线路、车站与方向；官方实时到站只显示分钟，顶部新增刷新，刷新图标常态灰、按下变黑。
  • 巴士时刻表
    「口岸巴士」更名为「巴士时刻表」，顶部补同款刷新按钮。
  • 打卡即归档与皇岗小巴
    保存上学记录（含自动保存）即写入通勤档案；皇岗口岸 B 字头下新增 44B1、N44B、79S、616S 四条小巴，统一「小巴」标签。
  • 英文与视觉
    通勤路径与港铁时刻表补齐中英文；路径卡片改为液态玻璃与 24px 圆角，区域标签中性化，底部编辑弹层保持原样。
